The World in One Day — Monday 23 November 2026. A program that draws one 1024×1024 front page summing up the day's world news in one image: 45 stories, 3 heroes (COP31 collapses in Antalya, Ukraine sinks the Russian corvette Merkury at Benghazi, tankers attacked in the Strait of Hormuz), a world map with 13 numbered pins, and 19 briefs. Everything is drawn with PIL primitives — no network, no external images — and the bundled DejaVu fonts make the render deterministic.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024 PNG, under 1 MiB). Running it twice produces identical bytes.
